# MOVIE4U — Starter Website

เว็บแคตตาล็อกภาพยนตร์และซีรีส์ โทนดำ-แดง พัฒนาด้วย Next.js 15 และ React 19

## เริ่มใช้งานบนเครื่อง

1. ติดตั้ง Node.js รุ่น LTS (แนะนำ Node.js 20 ขึ้นไป)
2. แตกไฟล์ ZIP แล้วเปิด Terminal ในโฟลเดอร์ `movie4u`
3. ติดตั้งแพ็กเกจ:

   ```bash
   npm install
   ```

4. เปิดเซิร์ฟเวอร์สำหรับพัฒนา:

   ```bash
   npm run dev
   ```

5. เปิด `http://localhost:3000`

ตรวจสอบ build ก่อนนำขึ้น Vercel:

```bash
npm run build
```

## นำขึ้น Vercel

1. อัปโหลดโฟลเดอร์นี้เข้า GitHub repository
2. เข้า Vercel แล้วเลือก **Add New → Project** และ Import repository
3. Framework จะตรวจพบ Next.js อัตโนมัติ ใช้ค่า Build Command `npm run build`
4. กด Deploy

## สิ่งที่มีในชุดนี้

- หน้าแรกพร้อม Hero section และแคตตาล็อกหนัง/ซีรีส์
- ค้นหาชื่อเรื่องและกรองตามหมวดหมู่
- หน้าต่างรายละเอียดภาพยนตร์
- บันทึกรายการโปรดใน Local Storage ของเบราว์เซอร์
- Responsive สำหรับมือถือและเดสก์ท็อป

## ข้อจำกัดที่ควรทราบ

ชุดนี้เป็น **Frontend Starter** ไม่ใช่แพลตฟอร์มสตรีมมิงที่พร้อมเปิดให้บริการเต็มรูปแบบ ยังไม่มีระบบสมัครสมาชิก/เข้าสู่ระบบ, ฐานข้อมูล, ระบบผู้ดูแล, API จัดการเนื้อหา, ระบบชำระเงิน หรือระบบเล่นวิดีโอจริง ปุ่มเล่นและรายละเอียดเป็นตัวอย่าง UI เท่านั้น

ก่อนเปิดให้บริการจริง ต้องเชื่อม backend และระบบจัดเก็บวิดีโอที่เหมาะสม พร้อมกำหนดสิทธิ์เข้าถึงและมาตรการรักษาความปลอดภัย ใช้เฉพาะภาพยนตร์/ซีรีส์/ตัวอย่างที่คุณมีสิทธิ์เผยแพร่เท่านั้น

ภาพโปสเตอร์ตัวอย่างโหลดจาก TMDB image CDN; ควรตรวจสอบเงื่อนไขการใช้งานและตั้งค่าการแสดงเครดิตตามข้อกำหนดของผู้ให้บริการก่อนใช้งานจริง
